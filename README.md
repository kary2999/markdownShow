# Markdown Show

拖拽即渲染的 Markdown 展示工具。两种用法：

1. **网页版（PWA）** — 浏览器直接打开，拖 `.md` 进去即渲染，可"装到桌面像 App 一样打开"。部署在 GitHub Pages。
2. **Chrome 扩展** — 自动接管浏览器里打开的 `.md` / `.markdown` 链接。

## 功能总览

| 能力 | 说明 |
| --- | --- |
| 多格式展示 | Markdown、PDF、HTML、图片、XMind 思维导图、SQL、JSON、Excel / CSV 表格 |
| 本地文件夹管理 | 树状浏览、筛选、新建/重命名/删除、强刷新 |
| 编辑模式 | 左编辑 / 右预览，双向同步滚动，保存与另存为 |
| 粘贴路径打开 | 粘贴 `/Users/you/doc.md` 即识别并打开 |
| 正文搜索 / 替换 | Ctrl/Cmd+F，支持代码块；编辑模式下搜源码，并可逐个 / 全部替换 |
| 演示模式 | 把文档变成全屏幻灯片 |
| 导出 | 打印为 PDF、导出独立 HTML |
| 外观 | 亮/暗主题 + 三种风格皮肤 |
| 其他 | 目录 TOC、Mermaid、代码高亮、DOMPurify 清洗、多文档 Tab、离线可用（PWA） |

> 纯前端，无后端。文件内容只在你的浏览器里处理，不会上传。

## 网页版（推荐）

在线访问：`https://kary2999.github.io/markdownShow/`

- 支持离线（Service Worker 缓存）与安装到桌面（PWA）
- 文件夹管理、保存、粘贴路径依赖 **File System Access API**，需要 Chrome / Edge 等 Chromium 内核浏览器；Safari / Firefox 只能用拖拽或「打开」选文件

本地预览：

```bash
python3 -m http.server 4599
# 打开 http://localhost:4599/
```

## 使用说明

### 1. 打开文件

三种方式，可同时打开多个，顶部 Tab 切换（有未保存修改的 Tab 前会显示 `●`）：

- **拖拽**：把文件拖到页面任意位置
- **点「📂 打开」**：系统选择框，可多选
- **粘贴路径**：见下文「粘贴路径打开」

按扩展名自动选择展示方式：

| 类型 | 扩展名 | 展示方式 |
| --- | --- | --- |
| Markdown | `.md .markdown .mdown .mkd .mdx .txt` | 渲染 + 目录，可编辑 |
| PDF | `.pdf` | 浏览器原生阅读器 |
| HTML | `.html .htm` | 沙箱 iframe，脚本可运行，但读不到本站数据 |
| 图片 | `.png .jpg .jpeg .gif .webp .svg .bmp .avif .ico` | 居中显示，点击放大 |
| XMind | `.xmind` | 解压后转为思维导图（只读） |
| 表格 | `.xlsx .xlsm .csv .tsv` | 渲染成表格（只读）：表头吸顶、可横向滚动；xlsx 每个工作表一节，日期自动转成 `yyyy-mm-dd`；CSV 自动识别 UTF-8 / GBK；单表最多显示前 5000 行 |
| Numbers | `.numbers` | 暂不支持直接展示（苹果私有格式）；会给出导出为 Excel / CSV 的操作指引 |
| SQL / JSON | `.sql .json` | 语法高亮的代码视图（只读），可复制、可搜索；压缩成一行的 JSON 自动格式化，不合法的 JSON 原样显示 |

用「打开」按钮或文件夹面板打开的文件会保留文件句柄：磁盘上的文件被外部修改后，Markdown 每 2 秒自动同步；拖拽进来的文件没有句柄，需要点「🔄 刷新」重新读取。

### 2. 本地文件夹管理

点顶部「🗂 文件夹」打开侧边面板：

1. 点「选择文件夹」授权一个目录（**Chrome 不允许直接选用户主目录**，请选具体的子目录，如 `Code`、`Documents/notes`）
2. 目录树按需加载：点开哪一层才读取哪一层，几千个文件的大目录也不卡；某个子目录读取失败只标记它自己，不影响其他
3. 点击文件即打开，支持的类型都能点
4. 顶部输入框可按文件名筛选（含子目录，索引在后台建立）
5. 「🔄 强刷新」清掉索引缓存并重新扫描磁盘；「📂 更换」切换到另一个文件夹
6. 底部按钮可 **新建文件 / 新建文件夹 / 重命名 / 删除**。名称会校验，删除前二次确认，**删除不可撤销**
7. 隐藏文件（以 `.` 开头）和 `node_modules` 默认不显示

下次打开页面会记住上次的文件夹；浏览器回收了授权时，面板里点一下即可重新连接。文件索引快照存在 localStorage，用于秒开和离线筛选，不含任何文件内容。

### 3. 编辑与保存

点「✏️ 编辑」进入编辑模式，左边写、右边即时预览（约 160ms 防抖）：

- **同步滚动**：滚左边，右边跟到对应位置；滚右边，左边也跟回来。按标题、段落、代码块逐块对齐，不是简单按百分比。图片很多的文档可能有小偏差
- **保存**（Ctrl/Cmd+S）：写回原文件，第一次会请求一次写权限
- **另存为**：存成新文件，之后该 Tab 指向新文件
- 编辑器里按 Tab 插入两个空格
- 拖拽进来的文件没有句柄，无法直接保存，请用「另存为」（浏览器的安全限制）
- XMind、PDF、HTML、图片、SQL、JSON、表格不可编辑

再点一次「编辑」回到纯预览。

### 4. 粘贴路径打开

在页面空白处（光标不在输入框里）粘贴文件路径，如 `/Users/you/notes/todo.md`。支持 `/`、`~/`、`C:\` 开头，带引号、`file://`、`%20` 也行。

> 浏览器不允许网页凭路径字符串读取本地文件，所以首次需要授权一次包含该文件的目录。

- **已授权过**：只要路径落在已授权目录里，粘贴即开，没有任何提示
- **没授权过**：顶部弹出提示条，点「授权『xxx』并打开」，在选择框里选中那个文件夹，文件立刻打开，之后该目录下的路径粘贴即开
- 想一次覆盖更多，授权上层目录（如 `Code`）即可
- 提示条上的「手动选文件」：不授权目录，直接在选择框里手选这个文件
- 隐藏目录（如 `.claude`）在选择框里按 `Cmd+Shift+.` 才能看到

### 5. 正文搜索

`Ctrl/Cmd+F`（或点 🔍）打开搜索条：

- Enter / Shift+Enter 跳到下一个 / 上一个，Esc 关闭，显示 `当前/总数`
- 能搜到代码块里的内容，包括被语法高亮拆开的词
- 编辑模式下搜索作用于左侧源码：跳转时在编辑器里选中命中处，右侧预览同时高亮；此时的计数是源码里的匹配数
- **替换**（仅编辑模式）：搜索条下方多出「替换为…」一行
  - 「替换」（或在替换框按 Enter）：替换当前命中并跳到下一个；当前没有选中命中时，第一次点击只负责定位
  - 「全部替换」：整篇一次替换，显示 `已替换 N`
  - 查找不区分大小写，替换文字按你输入的原样写入；替换内容是通过编辑器写入的，Cmd/Ctrl+Z 可撤销（全部替换算一步，撤销前请先点回编辑区）
- 仅作用于 Markdown；PDF / HTML 请用浏览器自带查找

### 6. 演示模式

点「▶ 演示」把当前文档变成全屏幻灯片：

- 文档里有 `---` 分隔线时，按分隔线分页；没有时按 `#` / `##` 标题分页
- `←` `→` / PageUp / PageDown / 空格 翻页，`F` 全屏，`Esc` 退出

### 7. 导出

- **PDF**：调用浏览器打印，选「另存为 PDF」
- **HTML**：导出带样式的独立 `.html` 文件，离线也能打开

### 8. 外观

- 🌓 切换亮/暗主题（记忆选择，默认跟随系统）
- 🎨 循环切换风格：刊物 → 极简 → 活泼
- 点击图片和 Mermaid 图可放大；代码块右上角有「复制」按钮

### 常见问题

- **文件夹面板点了没反应 / 没弹选择框**：请在独立浏览器窗口打开，不要用内嵌预览
- **提示没有写权限**：保存时在浏览器弹窗里点「允许」
- **页面更新后没变化**：强刷一次（Cmd/Ctrl+Shift+R）；PWA 默认联网优先，离线才用缓存

## Chrome 扩展

见 [`extension/`](extension/)。

1. 打开 `chrome://extensions/` → 开启开发者模式
2. 「加载已解压的扩展程序」→ 选择 `extension/` 目录
3. **开启「允许访问文件网址」**（详情页里）：接管本地 `.md` 与路径读取都依赖它

能力：

- **自动接管**：打开任何 `.md/.markdown/.mdown/.mkd/.mdx` 链接（file:// 或 http(s)://）自动渲染
- **查看器页面**：点工具栏图标打开，支持
  - 粘贴本地绝对路径（如 `/Users/you/doc.md`）→ 直接展示
  - 拖拽 / 选择多个文件，Tab 切换
- 也可用 URL 直达：`viewer.html?file=/Users/you/doc.md`

## 技术说明

- mermaid 用 v10 UMD 单文件（v11 是 ESM 分包，无法当经典脚本用）。
- marked v12 移除了 `highlight` 选项，改为解析后 `hljs.highlightElement` 逐块高亮。
- 网页版与扩展共享同一套渲染逻辑与样式（扩展版内联在 content.js/viewer.css，网页版在 app.js/app.css）。
